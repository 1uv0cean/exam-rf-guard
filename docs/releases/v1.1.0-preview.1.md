# RF 스위퍼 v1.1.0-preview.1

잠깐 나타났다 사라지는 이어폰의 기록 보존과 재등장, 주소 합집합, 예상 거리를 강화했습니다.

- **관측 구간·재등장**: 첫 포착과 재포착, 각 구간 수신 횟수와 미수신 시간을 저장합니다. BLE 15초·Wi-Fi 90초 초과 공백을 기준으로 구간을 나누며 지연 패킷이 공백을 메우면 합칩니다.
- **전체 이력 / 합집합**: 선택한 입실 전 기준부터 비교 시점까지 같은 공간·모드의 저장 자료와 비교 대상에 등장한 주소를 중복 없이 표시합니다. 카드 이력은 가장 최근 수신된 탐색 기준이며 스냅샷의 누적 횟수를 더하지 않습니다. 저장하지 않은 이전 탐색은 포함되지 않습니다.
- **예상 거리**: 마지막 EMA RSSI를 실내 전파 모델로 환산합니다. 1m 기준이 없으면 −59 dBm 가정과 `미보정`을 표시합니다. 상세에는 계산 가정 범위를 표시하며 실제 거리나 통계적 신뢰구간은 아닙니다. 재등장 시 오래된 세기를 섞지 않습니다.
- **아이콘**: 이어폰·헤드폰·Bluetooth·Wi-Fi·시간·재등장·합집합·거리·저장·완료를 짧은 레이블과 함께 표시합니다.
- 저장 형식 v2로 구간과 보정 기준을 보관합니다. 기존 v1 자료를 읽을 수 있으며 구간이 없으면 재등장 기록을 추측하지 않습니다. v2 저장 후 이전 앱으로 자료 읽기는 지원하지 않습니다.

## 시험장 시나리오 검증

입실 전 AP 저장 → 이어폰을 1초 동안 2회 포착 → 약 2분 미수신에도 추가 기록 유지 → 같은 주소 재등장 → 2개 구간·재등장 1회·1분 59초 미수신 표시 → 합집합 2개를 순수 추적기와 Android UI에서 검증했습니다. 저장소 재생성 후의 이력 복원, 다른 공간·모드·미래 자료 제외, 단발 수신과 오래된 거리 표현도 검사합니다.

총 77개 테스트 통과, APK 빌드와 lint 검사 완료. 실제 RF 수신·물리 거리 정확도의 현장 검증은 별도입니다. 시나리오 화면은 자동 관측 자료로 실행한 Android UI입니다.

## 다운로드

- `rf-sweeper-v1.1.0-preview.1-debug.apk`: Android 10 이상, versionCode 2. 이전 프리뷰와 같은 debug 서명의 설치용 검증 APK입니다.
- `SHA256SUMS.txt`: APK 검증 해시.
- `QUICKSTART.ko.md`, `flow-*.png`, `scenario-*.png`: 사용 안내, 연습 모드 흐름과 단속적 수신·재등장 검증 화면.

추가 주소는 부정행위 판정이 아닙니다. 모델은 광고 이름 기반 후보이며 거리와 수신 구간은 실제 위치·연결 지속 시간의 증명이 아닙니다. Wi-Fi는 Android의 탐색 빈도 제한을 따릅니다.

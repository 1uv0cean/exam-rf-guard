# RF Sweeper v1.2.0-preview.1

전파 수신·기록·비교에 집중한 시험장용 업데이트입니다.

- 입실 전 기준에 해당 탐색에서 한 번 이상 포착한 주소 전체를 포함합니다. 일시적으로 사라진 배경 신호가 재등장했을 때 신규로 잘못 보이는 일을 줄입니다.
- 5초마다·정상 탐색 중지 시 전체 신호 이력을 자동 보존합니다. 수동 저장을 누르지 않아도 단발 신호를 보관함에서 다시 볼 수 있습니다. 세션별 누적 기록과 기존 수동 스냅샷은 분리합니다.
- BLE·Wi-Fi 수신 상태, 첫 결과 대기, 마지막 갱신, 오류를 보여주는 수신 상태 탭을 추가했습니다. BLE 실패 상태를 탐색 중으로 유지하지 않으며 Wi-Fi 빈 결과와 미완료를 구분합니다.
- 스마트 안경·스마트워치·카메라 이름 기반 후보와 유형 아이콘, 한국어 검색을 추가했습니다. 제조사 코드만으로 제품 유형이나 AI 사용을 추정하지 않습니다.
- 선택된 비교 결과·주소 합집합·관측 구간·재등장·RSSI·거리 기준을 텍스트 파일로 저장할 수 있습니다. 시스템 파일 선택기를 열기 전 내용이 고정됩니다.
- Activity 재생성 시 상태 유지, 종료 시 저장, 이전/새 인스턴스의 자동 저장 병합을 보강했습니다. 첫 수동·자동 저장 후에는 탐색 공간을 고정합니다.

## 검증과 설치

단위·Robolectric Android UI 테스트 116개가 모두 통과했고 debug APK 빌드와 Android Lint를 완료했습니다. 릴리즈에 실제 Android UI의 연습·결정적 관측 자료 캡처와 보고서 예시를 포함합니다. 실기기 무선 수신률·배터리·거리 오차 검증은 별도입니다.

Android 10 이상. 설치 가능한 debug 서명 APK이며 이전 preview와 같은 서명입니다. 정식 배포용 서명 APK는 아닙니다.

## 관측 범위

BLE 광고와 Wi-Fi AP를 관측합니다. 광고하지 않는 연결 기기, 셀룰러, 유선 장비, 통신 내용은 이 앱으로 잡지 못합니다. 주소 수는 물리적 장비 수가 아니며 제조사·모델·거리 표시는 후보·추정값입니다.

5초 자동 저장 사이 또는 강제 종료 직전 미저장 구간은 유실될 수 있습니다. 앱을 벗어나면 수신은 중지됩니다. 합집합은 선택한 기준~비교 범위의 같은 공간·모드 자료를 사용하며 중복 스냅샷 수신 횟수를 합산하지 않습니다.

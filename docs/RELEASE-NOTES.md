# RF 스위퍼 v1.0.0-preview.1

빈 시험장 환경을 저장하고 입실 후 추가된 BLE·Wi-Fi 주소를 비교하는 Android 프리뷰입니다.

- 입실 전 저장 → 입실 후 비교 → 추가 장비 확인의 고정 진행 표시.
- 장비 유형·제조사 단서·모델 후보·관측 구간과 수신 횟수 요약.
- 결과 해석·식별 근거·시점별 관측 기록 펼쳐보기.
- 공간별 스냅샷 저장과 검색, 추가·미관측·공통 주소 비교.
- BLE 연속 수신, 짧게 등장한 신호의 이력 보존, 오래된 Wi-Fi 캐시와 이전 세션 콜백 제외.
- 오프라인 IEEE MAC 등록사 및 Bluetooth SIG 광고 회사 조회, 이어폰·헤드폰의 이름 기반 모델 후보 해석.

## 첨부 파일

- `rf-sweeper-v1.0.0-preview.1-debug.apk`: Android 10 이상에 설치 가능한 **debug 서명 검증용 APK**. 정식 배포 서명 빌드가 아닙니다.
- `SHA256SUMS.txt`: APK SHA-256 해시.
- `QUICKSTART.ko.md`: 버튼 위치와 결과 의미를 설명한 사용 안내. 화면 이미지는 같은 릴리즈의 PNG 첨부 파일 또는 저장소 `docs/screenshots/`에서 확인합니다.
- `flow-*.png`: 연습 데이터로 실행한 실제 앱 화면 4장.

## 검증 및 관측 범위

JUnit·Robolectric 테스트 65개 통과, debug APK 빌드와 lint 검사 완료. 320dp·글꼴 150%에서 추가 카드와 상세 정보 조작도 확인했습니다. 실기기의 Bluetooth·Wi-Fi 수신과 센서 정확도는 후속 현장 검증 대상입니다.

추가 주소는 확인 후보이며 부정행위 판정이 아닙니다. 모델 정보는 광고 이름에서 읽은 후보이고, 관측 구간은 연속 연결 시간이 아닙니다. Wi-Fi 갱신은 Android의 탐색 빈도 제한을 따릅니다.
